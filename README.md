## ✨ Características Principales

- **Diseño Orgánico y Responsive:** Interfaz adaptada a todos los dispositivos móviles, tablets y escritorio.
- **Selector Multimoneda Dinámico:** Cotización e inversión en **ARS**, **EUR** y **USD** con cambio automático de precios.
- **Módulos de Servicios Integrados:** Psicoterapia, Psicoastrología, Tarot, Registros Akáshicos y Paquetes de Bienestar.
- **Generador de Gift Cards:** Sistema interactivo con vista previa en tiempo real para solicitar vouchers de regalo vía WhatsApp.
- **Panel de Administración (API PHP + JSON):** Panel ligero en `admin.html` que permite modificar precios, servicios y textos de preventa sin tocar código.
- **Integración de Contacto Multi-canal:** Botones directos para WhatsApp Business, Instagram, TikTok, Telegram y Threads.
- **SEO & Datos Estructurados:** Optimización OpenGraph y JSON-LD Schema.org para psicólogos y terapeutas.
